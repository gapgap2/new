# AGF 제작 · 프레임 뷰어

AGF v35를 열어 재생하고, 수정 PNG를 교체한 뒤 새 AGF로 다운로드하는 도구입니다. 별도 패키지 설치 없이 최신 Chrome/Edge에서 동작합니다. 파일은 외부로 전송하지 않고 브라우저에서 처리합니다.

## 실행

ZIP 전체를 압축 해제한 뒤 `index.html`을 여세요. 로컬 파일 실행이 제한되는 환경에서는 이 폴더에서 다음 명령을 실행한 후 브라우저로 접속하세요.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저 주소: `http://127.0.0.1:8000/index.html`

## 사용

1. **AGF 열기**에서 파일을 선택합니다. 여러 모션을 함께 열 수 있습니다.
2. 재생·이전·다음·프레임 슬라이더로 모션을 확인합니다. FPS는 비교용이며 게임 속도를 뜻하지 않습니다.
3. 수정 PNG를 현재 프레임에 넣거나 `000.png`, `001.png`처럼 0부터 시작하는 번호 파일 여러 개를 넣습니다.
4. PNG 크기는 원본 캔버스와 같아야 하며 원본 저장 영역 밖에 불투명 픽셀이 있으면 거부합니다. 자동으로 그림을 늘리거나 자르지 않습니다.
5. **AGF 제작 · 다운로드**를 누릅니다. 인코딩 후 재추출하여 모든 프레임의 픽셀을 검사하고 다운로드합니다.

**이 도구는 새 외형을 자동으로 그리지 않습니다.** PNG를 교체하지 않으면 `repacked_original.AGF`, 교체하면 `edited.AGF`로 저장합니다. 수정하지 않은 프레임은 원본으로 남습니다. 흰색 수영복·긴 흑발 시안의 641프레임 적용본은 포함되어 있지 않습니다.

16:9는 뷰어의 표시 영역 비율입니다. AGF 원본 캔버스(512×512 또는 320×260)와 좌표를 유지하고, 캐릭터의 비율을 가로로 늘리지 않습니다.

## 입력 AGF

이 패키지에는 원본 AGF나 수정 외형 프레임을 포함하지 않습니다. 보유한 AGF를 **AGF 열기**로 불러오세요. 사용자가 마지막에 제공한 창 모션 14개, 총 641프레임을 사용해 검증했습니다. 원본은 별도로 보관하세요.

## 검증과 한계

- JavaScript와 독립적인 Python 디코더의 14개·641프레임 픽셀 일치 확인.
- 14개 각각 무수정 재저장 후 압축 전 바이트·좌표·프레임 수 일치 확인.
- 14개 각각 한 프레임의 픽셀 수정 후 재저장·재추출 일치 확인.
- Chromium에서 파일 14개 열기, 재생, PNG 교체·취소, 원본/수정 AGF 다운로드와 내부 재추출 검사 확인.
- 원본 프레임 수·순서·캔버스·저장 좌표와 알 수 없는 헤더 필드를 유지합니다. 투명 픽셀의 숨겨진 RGB는 저장하지 않습니다.
- 게임 클라이언트에서의 로딩·렌더링은 검증하지 않았습니다. 내부 파일 검증 통과가 게임 호환성 보장은 아닙니다.

코드: `index.html`(화면), `agf.js`(AGF 읽기·쓰기). 번들에 포함된 `agf_tool.py`는 별도 Python CLI이며 Pillow가 필요합니다. 사용 예:

```sh
python3 agf_tool.py extract /path/to/gwangmok_gs_n.AGF extracted_n
python3 agf_tool.py pack /path/to/gwangmok_gs_n.AGF extracted_n edited_n.AGF
```
