AGF 파일을 선택하세요. Chrome 또는 Edge 최신 버전을 권장합니다.
사용 방법과 검증 범위
  1. AGF 파일을 여세요. 여러 파일을 선택하면 목록에서 모션을 바꿀 수 있습니다.
  2. 슬라이더로 프레임을 선택하고 수정 PNG를 교체하세요. PNG 크기는 원본 캔버스와 같아야 합니다.
  3. 여러 PNG는 000.png, 001.png처럼 0부터 시작하는 프레임 번호로 이름을 지정하세요. 오류가 있으면 해당 묶음 전체를 적용하지 않습니다.
  4. 원본 저장 영역 밖의 불투명 픽셀은 거부합니다. 그림을 자동 변형·축소·잘라내지 않습니다.
  5. 출력 모션을 확인하고 AGF를 저장하세요. 저장 직전에 재추출 검사를 실행합니다. 교체하지 않은 프레임은 원본으로 유지됩니다.

지원: 제공된 AGF v35. 원본 프레임 수·순서·캔버스·저장 좌표와 알 수 없는 헤더 필드를 유지합니다. 투명 픽셀의 숨겨진 RGB는 보존하지 않습니다. 내부 재추출 검사와 게임 내 정상 작동은 서로 다른 검증입니다. 게임 클라이언트 호환성은 미검증이므로 원본을 보관하세요.
