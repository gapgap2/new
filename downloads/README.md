# 야마천 의상 변경 검토본

- [수정 AGF 11개 ZIP (약 9MB)](yamantaka_AGF.zip?raw=true)
- [전체 PNG 및 원본 비교 뷰어 ZIP (약 30MB)](yamantaka_full.zip?raw=true)

전체 ZIP을 압축 해제한 뒤 `viewer.html`을 브라우저에서 열면 원본과 수정본을 비교할 수 있습니다.

11개 AGF, 총 444프레임에 의상 변경을 적용한 검토본입니다. 원본 캔버스와 프레임 저장 좌표를 유지했고, 재포장한 AGF를 재추출하여 수정 PNG와 이미지 데이터가 일치하는 것을 확인했습니다.

생성된 세부 자세와 윤곽은 원본과 다를 수 있습니다. 손과 발의 모든 픽셀이 원본과 일치하는 완성본은 아니며, 거상 내 작동은 검증하지 않았습니다.
