# 각성 군다리 → 부동명왕 외형·모션·음성 교체

- [교체 ZIP 다운로드 (약 31MB)](gundari_over_acala.zip?raw=true)
- [부동명왕 원본 복구 ZIP 다운로드 (약 14MB)](acala_original_restore.zip?raw=true)

교체본에는 군다리 AGF 10개·456프레임과 음성 YAV 5개를 부동명왕의 대응 파일명으로 넣었습니다. 군다리 원본 파일 내용은 변경하지 않았습니다. 선택 음성 1~3, 공격, 사망 음성을 포함합니다. `_WB_`는 부동명왕 `_w_` 파일에 대응합니다.

## 적용

게임을 종료하고 현재 설치 파일을 먼저 백업한 뒤, 교체 ZIP의 AGF/YAV 파일을 **각각 같은 이름의 기존 파일이 있던 위치**에 덮어씁니다. ZIP의 AGF/YAV는 분류용 폴더이며 실제 게임 폴더명을 뜻하지 않습니다. 자세한 대응표와 안내는 ZIP 안에 있습니다.

복구 ZIP은 이번에 첨부한 부동명왕 원본 15개입니다. 현재 설치 버전이 다르면 교체 전에 직접 백업한 파일로 복구하세요.

## 검증 범위

원본 AGF 20개·894프레임의 추출을 확인했습니다. 교체본 15개는 군다리 원본과, 복구본 15개는 부동명왕 원본과 바이트 단위로 일치합니다. ZIP 무결성 검사와 모든 파일의 SHA-256 비교를 통과했습니다. 양측 음성은 PCM 44.1kHz·16비트·모노입니다.

군다리와 부동명왕은 캔버스 크기 및 공격·사망 프레임 수가 다릅니다. 군다리의 모션 전체를 보존한 파일명 교체본으로, 거상 클라이언트에서 모션·위치·음성 트리거의 호환성은 아직 검증하지 못했습니다.
