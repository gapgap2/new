## 식별 정정

사용자가 부동명왕으로 제시한 두 번째 사진과 일치하는 회색 피부·백발·금색 관 장식 얼굴은 `PORTRAIT_INVEN_4.AGF`의 **54번**입니다. 금발·녹안·땋은 머리의 대위덕 후보는 **168번**입니다. 번호는 0부터 계산합니다.

앞서 눈 초상화 16번을 부동명왕으로 단정한 것은 잘못이었습니다. 수정본에서는 두 눈 초상화 묶음의 16번을 원본으로 되돌렸습니다.

## 이번 작업

- 인벤토리 54번: 각성 군다리의 은발·주황 눈·검은 털 갑옷 외형으로 새로 제작한 초상화.
- 인벤토리 168번: 흰 블라우스·금발·녹안의 대위덕 수정 외형에 맞춘 초상화.
- `portrait_mercenary_l2/s2.AGF` 14번: 대위덕의 수정 눈 초상화 유지.
- 두 눈 초상화 묶음의 16번: 잘못된 식별에 따른 교체 취소, 첨부 원본으로 복구.

군다리 정사각형 초상화는 캐릭터 외형을 참고해 새로 그린 이미지이며, 원본 군다리 인벤토리 슬롯에서 추출한 이미지가 아닙니다.

수정 AGF 3개의 900슬롯을 재추출해 검사했습니다. 의도적으로 수정한 4슬롯을 제외한 896개 프레임 레코드는 원본과 바이트 단위로 같습니다. 모든 캔버스 크기·슬롯 개수·저장 영역을 보존했습니다.

## 남은 부분

사진 2의 회색 신 얼굴과 일치하는 가로 눈 초상화는 제공된 l2/s2에서 식별하지 못했습니다. 모든 UI 초상화를 마치려면 다른 `portrait_mercenary_l/s` 묶음을 추가로 확인해야 합니다. 게임 클라이언트 표시는 검증하지 못했습니다.

게임을 종료하고 현재 파일을 백업한 뒤, 새 ZIP의 AGF 3개를 각각 같은 이름의 기존 파일 위치에 복사하세요. 자세한 설명은 ZIP의 README에 있습니다.
