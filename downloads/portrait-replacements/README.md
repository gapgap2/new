`portrait_mercenary_l2.AGF`와 `portrait_mercenary_s2.AGF`에서 부동명왕으로 식별한 눈 초상화를 군다리 원본으로 바꾸고, 대위덕의 눈 초상화를 금발·녹안의 새 외형에 맞췄습니다. 원본 캐릭터 모델의 머리 모양·이마 장식과 초상화를 시각적으로 대조해 식별했습니다. 변경한 프레임은 두 파일 각각 14번과 16번(0부터 계산)이며, 각 298개 비대상 프레임은 원본의 압축 해제 레코드와 바이트 단위로 일치합니다. 저장 좌표와 캔버스 크기, 300슬롯 개수를 보존하고 600슬롯을 재추출해 검증했습니다.

## 아직 완료되지 않은 범위

전체 초상화 교체 완료본은 아닙니다. 제공된 `PORTRAIT_INVEN_4.AGF`에서는 세 캐릭터의 80×80 대상 슬롯을 식별하지 못해 변경하지 않았습니다. `PORTRAIT_INVEN`으로 시작하는 나머지 초상화 묶음을 추가로 확인해야 합니다.

ZIP 안의 `portraits/yamantaka_inventory_80.png`는 대위덕용 준비 이미지이며, 인벤토리 AGF에 아직 삽입되지 않았습니다. 새 초상화의 고해상도 이미지도 함께 들어 있습니다.

게임을 종료하고 현재 파일을 백업한 뒤, 수정 AGF 두 개를 각각 같은 이름의 기존 파일 위치에 복사합니다. 게임 클라이언트에서 실제 UI 표시는 아직 검증하지 못했습니다. 복구 ZIP은 이번에 첨부한 원본 두 개입니다.
