# 초상화 식별 정정 — 기존 다운로드도 수정본으로 갱신

사용자가 제공한 사진과 대조하여 이전 16번 슬롯의 부동명왕 추정을 철회했습니다. 두 눈 초상화 묶음의 16번은 원본으로 복구했습니다.

- [정정된 교체본 다운로드](portraits_eye_strip_partial.zip?raw=true)
- [원본 AGF 3개 복구본 다운로드](portraits_eye_strip_restore.zip?raw=true)
- [정정된 원본/수정 비교 이미지](before_after.png)
- [최신 설명과 식별 결과](https://github.com/gapgap2/new/tree/portrait-photo-matched/downloads/portrait-photo-matched)

기존 파일명 링크는 유지하되 내용은 사진 대조 후 수정본으로 교체했습니다. 새 교체 ZIP에는 가로 눈 초상화 2개와 인벤토리 초상화 1개, 총 AGF 3개가 들어 있습니다. 두 번째 사진과 일치하는 인벤토리 얼굴은 54번이고, 금발·녹안 대위덕 후보는 168번입니다. 슬롯 번호는 0부터 계산합니다.

군다리의 정사각형 초상화는 외형을 참고해 새로 그린 이미지입니다. 900슬롯을 재추출해 검사했고, 의도적으로 수정한 4슬롯 외 896개 프레임 레코드를 원본 그대로 보존했습니다.

회색 신 얼굴의 가로 눈 초상화가 들어 있는 다른 portrait_mercenary 묶음은 추가 확인이 필요합니다. 모든 UI 초상화 교체 완료본이나 게임 내 검증 완료본은 아닙니다.
